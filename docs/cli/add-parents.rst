================
grgr add-parents
================

.. program:: grgr-add-parents

Link a child to one or two parents, filling a missing parent slot in an existing family if
possible.

.. code-block:: text

    Usage: grgr add-parents [OPTIONS] CHILD_ID PARENT1_ID [PARENT2_ID]

Arguments
=========

.. option:: CHILD_ID

    Child's person ID.

.. option:: PARENT1_ID

    First parent's person ID.

.. option:: PARENT2_ID

    Second parent's person ID (optional).

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
