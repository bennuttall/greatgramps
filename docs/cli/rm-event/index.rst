=============
grgr rm-event
=============

.. program:: grgr-rm-event

Delete one or more events, removing all references from people and families.

.. code-block:: text

    Usage: grgr rm-event [OPTIONS] EVENT_IDS...

Arguments
=========

.. option:: EVENT_IDS

    One or more event IDs to delete.

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
