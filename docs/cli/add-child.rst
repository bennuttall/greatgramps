==============
grgr add-child
==============

.. program:: grgr-add-child

Link an existing person as a child to one or two parents.

.. code-block:: text

    Usage: grgr add-child [OPTIONS] CHILD_ID PARENT1_ID [PARENT2_ID]

Arguments
=========

.. option:: CHILD_ID

    Child's person ID.

.. option:: PARENT1_ID

    First parent's person ID.

.. option:: PARENT2_ID

    Second parent's person ID (optional).

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
