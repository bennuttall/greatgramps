==================
grgr update-person
==================

.. program:: grgr-update-person

Set or update event dates and places on a person.

.. code-block:: text

    Usage: grgr update-person [OPTIONS] PERSON_ID

Arguments
=========

.. option:: PERSON_ID

    Person ID.

Options
=======

.. option:: --birth TEXT

    Birth date, e.g. ``'1 Jan 1950'`` or ``1950``.

.. option:: --death TEXT

    Death date.

.. option:: --baptism TEXT

    Baptism date.

.. option:: --burial TEXT

    Burial date.

.. option:: --birth-place TEXT

    Birth place ID or name.

.. option:: --death-place TEXT

    Death place ID or name.

.. option:: --burial-place TEXT

    Burial place ID or name.

.. option:: -y, --yes

    Skip confirmation prompt.
