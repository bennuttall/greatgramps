====================
grgr add-event-place
====================

.. program:: grgr-add-event-place

Set the place on an existing event.

.. code-block:: text

    Usage: grgr add-event-place [OPTIONS] EVENT_ID PLACE_QUERY

Arguments
=========

.. option:: EVENT_ID

    Event ID.

.. option:: PLACE_QUERY

    Place ID or name to search for.
