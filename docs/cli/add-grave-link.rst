===================
grgr add-grave-link
===================

.. program:: grgr-add-grave-link

Add a Find A Grave URL to a person.

.. code-block:: text

    Usage: grgr add-grave-link [OPTIONS] PERSON_ID MEMORIAL

Arguments
=========

.. option:: PERSON_ID

    Person ID.

.. option:: MEMORIAL

    Find A Grave memorial ID or full URL.

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
