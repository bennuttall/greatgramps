==================
grgr enclose-place
==================

.. program:: grgr-enclose-place

Set one place as enclosed by another (GRAMPS 'Enclosed by' relationship).

.. code-block:: text

    Usage: grgr enclose-place [OPTIONS] CHILD_QUERY PARENT_QUERY

Arguments
=========

.. option:: CHILD_QUERY

    Place ID or name to be enclosed.

.. option:: PARENT_QUERY

    Place ID or name that encloses it.

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
