=====================
grgr add-event-people
=====================

.. program:: grgr-add-event-people

Link people to an existing event.

.. code-block:: text

    Usage: grgr add-event-people [OPTIONS] EVENT_ID PERSON_IDS...

Arguments
=========

.. option:: EVENT_ID

    Event ID.

.. option:: PERSON_IDS

    One or more person IDs to link to the event.

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
