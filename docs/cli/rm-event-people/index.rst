====================
grgr rm-event-people
====================

.. program:: grgr-rm-event-people

Remove one or more people from an event.

.. code-block:: text

    Usage: grgr rm-event-people [OPTIONS] EVENT_ID PERSON_IDS...

Arguments
=========

.. option:: EVENT_ID

    Event ID.

.. option:: PERSON_IDS

    One or more person IDs to remove from the event.

Options
=======

.. option:: -y, --yes

    Skip confirmation prompt.
