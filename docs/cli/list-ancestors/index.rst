===================
grgr list-ancestors
===================

.. program:: grgr-list-ancestors

List ancestors of a person grouped by generation.

.. code-block:: text

    Usage: grgr list-ancestors [OPTIONS] PERSON_ID

Arguments
=========

.. option:: PERSON_ID

    Person ID.

Options
=======

.. option:: -n, --generations INTEGER

    Limit to this many generations.
